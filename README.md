# Personal Profile Page

A simple, responsive personal profile website built with **HTML** and **CSS**.



## About

This project is a personal profile page that introduces me, my background and my interests. It was built as a learning project to practice front-end web development fundamentals.

## Features

- Clean and simple layout
- Profile photo and short introduction
- Styled with a separate CSS file
- Hosted for free on GitHub Pages
- No frameworks or libraries, just plain HTML and CSS

## Tech Stack

| Technology   | Purpose                     |
| ------------ | --------------------------- |
| HTML5        | Page structure and content  |
| CSS3         | Styling and layout          |
| GitHub Pages | Hosting                     |

## Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/anish-2007-hub/profile-.git
   ```
2. Go into the folder:
   ```bash
   cd profile-
   ```
3. Open `index.html` in your browser (double-click it, or use the Live Server extension in VS Code).

## Deployment

The site is deployed with **GitHub Pages** from the `main` branch (root folder).

To deploy your own copy:

1. Fork or clone this repository.
2. Go to **Settings → Pages**.
3. Under **Source**, choose **Deploy from a branch**.
4. Select the `main` branch and the `/ (root)` folder, then click **Save**.
5. Your site will be live at `https://<your-username>.github.io/<repo-name>/`.
